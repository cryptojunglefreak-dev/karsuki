풀 세트 · 22B

22B Full Set

22B 풀 세트는 완전한 패키지입니다. 모든 바디 패널에 범퍼와 리어 윙까지 더해, 한 번의 주문으로 22B 전환 전체를 커버합니다.

바디 패널(프런트 펜더와 리어 쿼터)은 0.8mm Zincore 아연도금 강판을 프레스하고 실제 22B를 스캔했으며, 일체형 플랜지로 용접부를 감추고 라인을 정확하게 유지합니다.

프런트/리어 범퍼와 리어 윙은 FRP 컴포지트로 성형하고 응력 부위에 카본을 보강, 고품질 에폭시 레진으로 합리적 무게에서 강도와 강성을 확보합니다. 모든 장착 하드웨어는 스테인리스입니다.

메시, 방향지시등, 스바루 엠블럼은 포함되지 않으며 순정 부품에서 옮기거나 별도로 구매하세요.

컴포지트 부품은 미도장 상태로 공급되며 범퍼는 블랙, 윙은 화이트입니다. 각 부품은 수작업 마감으로 도장 전 표준 가조립과 표면 준비가 필요합니다(고객 측 진행).

사양

  • 구성펜더, 쿼터, 범퍼, 윙
  • 패널0.8mm Zincore 강판
  • 컴포지트FRP + 카본, 에폭시
  • 하드웨어스테인리스
