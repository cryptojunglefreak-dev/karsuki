ชุดเต็ม · 22B

22B Full Set

ชุดเต็ม 22B คือแพ็กเกจครบ: ทุกแผงตัวถังพร้อมกันชนและสปอยเลอร์หลัง สั่งครั้งเดียวครอบคลุมการแปลงร่างเป็น 22B ทั้งคัน

แผงตัวถัง (แก้มหน้าและบังโคลนหลัง) ปั๊มจากเหล็กชุบสังกะสี Zincore 0.8 มม. สแกนจากรถ 22B จริง มีขอบพับในตัวช่วยซ่อนรอยเชื่อมและได้เส้นสายที่แม่นยำ

กันชนหน้า/หลังและสปอยเลอร์หลังขึ้นรูปจากคอมโพสิต FRP เสริมคาร์บอนในจุดรับแรง ใช้เรซินอีพ็อกซีคุณภาพสูงเพื่อความแข็งแรงและความแข็งแกร่งที่น้ำหนักเหมาะสม อุปกรณ์ยึดทั้งหมดเป็นสแตนเลส

ตะแกรง ไฟเลี้ยว และโลโก้ Subaru ไม่รวมในชุด ให้ย้ายจากชิ้นส่วนเดิมหรือซื้อแยก

ชิ้นส่วนคอมโพสิตจัดส่งแบบยังไม่พ่นสี กันชนสีดำและสปอยเลอร์สีขาว แต่ละชิ้นเก็บงานด้วยมือ ต้องลองประกอบและเตรียมผิวก่อนพ่นสี (โดยฝั่งของคุณ)

ข้อมูลจำเพาะ

  • ประกอบด้วยแก้มหน้า, บังโคลนหลัง, กันชน, สปอยเลอร์
  • แผงเหล็ก Zincore 0.8 มม.
  • คอมโพสิตFRP + คาร์บอน, อีพ็อกซี
  • อุปกรณ์ยึดสแตนเลส
