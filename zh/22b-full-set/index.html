22B Full Set

22B全套是完整方案：所有车身板件加上保险杠与尾翼，一次下单即可完成整车22B改装。

车身板件（前翼子板与后翼子板）由0.8mm Zincore镀锌钢板冲压而成，取自真车22B扫描，一体式翻边使焊缝隐藏、线条精准。

前后保险杠与尾翼由FRP复合材料成型，在高应力区加入碳纤维强化，并采用高品质环氧树脂，在合理重量下兼顾强度与刚性。所有安装配件均为不锈钢。

网格、转向灯与斯巴鲁标志不含在内，请从原厂部件移用或另行购买。

复合部件以未喷漆状态供货，保险杠为黑色、尾翼为白色；每件均手工修整，喷漆前需常规试装与表面准备（由您自行完成）。

规格

  • 内容翼子板、后翼子板、保险杠、尾翼
  • 板件0.8mm Zincore钢板
  • 复合件FRP + 碳纤维、环氧
  • 配件不锈钢
